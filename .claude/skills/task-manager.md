# task-manager

## 目的
Linearと連携した日次・週次タスク管理。
朝のヒアリングをもとに今日やることを決め、Linearに記録する。

## Linear設定
- チーム名: Yugodev
- チームID: dd512bc1（末尾省略・MCPで自動取得）

## トリガー
以下のフレーズで起動する：
- 「タスク確認して」
- 「今日のタスクを決めたい」
- 「Linearを更新して」

## 動作フロー

### Step 1: コンディション確認
以下の3問を順番にヒアリングする（まとめて聞いてよい）：
1. 昨夜の睡眠は取れましたか？
2. 今日の作業環境は？（自宅 / カフェ / 大学）
3. 気になっていることや集中を妨げるものはありますか？

回答をもとにコンディションレベルを判定：
- **Level A（好調）**: 睡眠OK・問題なし → 3〜5タスク、重要タスク優先
- **Level B（普通）**: 特に問題なし → 2〜3タスク
- **Level C（低調）**: 睡眠不足または悩みあり → 1〜2タスクのみ
- **Level D（要休養）**: 深刻な不調 → タスクは入れない、回復優先

判定後「今日はLevel X です。調整しますか？」と確認を取る。

### Step 2: 目標コンテキスト読み込み
`goals/quarterly.md` を読み込み、今期の優先事項を確認する。

### Step 3: タスク提案
コンディションレベルと今期目標に基づいてタスクを提案する。
タスクは以下のカテゴリから優先順に選ぶ：
1. インターン業務（最優先）
2. LeetCode演習
3. 英語学習
4. 筋トレ
5. 技術キャッチアップ

ユーザーの合意を得てからStep 4に進む。

### Step 4: Linearへ記録
合意したタスクをMCPでLinearのYugodevチームにissueとして作成する。
- タイトル: `[カテゴリ] タスク名`
- 優先度: コンディションに応じて設定（Level A→高、Level B→中、Level C/D→低）
- 期日: 今日

### Step 5: plans/daily/YYYY-MM-DD.md に記録
以下のフォーマットで `plans/daily/YYYY-MM-DD.md` を作成する：

```
# YYYY-MM-DD 日次プラン

## コンディション: Level X
## 今日のフォーカス
（1行）

## タスク一覧
- [ ] タスク1
- [ ] タスク2

## 今期目標との接続
（quarterly.md から引用して今日との繋がりを1行で）
```

## 制約
- コンディション確認なしにタスクを詰め込まない
- Linearへの書き込みは合意後のみ実行する
- 毎日のログは必ずplans/daily/に残す
